📖 名詞小字典

動畫中出現的名詞，這裡都用生活例子解釋

🟠 元素

盒子裡的每顆球，就是你存進去的資料（例如一個數字、一個名字）。

🔢 size（大小）

盒子裡「現在有幾顆球」。加一顆 +1，拿走一顆 -1。

📏 capacity（容量）

盒子「總共有幾格」，包含綠色虛線的預留空格。容量 ≥ 球數。

🏠 記憶體

電腦存放資料的大倉庫。你的盒子就放在倉庫裡的某個位置。

📮 位址

倉庫裡每個位置的「門牌號碼」，例如 0x1000。程式靠它找到你的盒子。

📝 指標

一張抄了門牌號碼的小紙條。方便隨時去找盒子——但盒子搬家後紙條就作廢了！

🚚 重新配置

盒子裝滿時，vector 自動換一個「兩倍大」的新盒子，把球全部搬過去，再丟掉舊盒子。搬家要花時間！

⚡ O(1) 和 O(n)

速度的成績單。O(1) = 不管多少資料都一樣快；O(n) = 資料越多越慢（像搬家的搬運過程）。

😱 新手最常犯的 3 個錯

先認識這些陷阱，以後就不會踩到

🔢 編號從 0 開始！
第一顆球是 0 號，不是 1 號。盒子裡有 10 顆球，編號是 0～9，沒有 10 號！
🚧 不要拿不存在的格子
盒子只有 4 格卻去拿 99 號，不會有人警告你！安全做法：先檢查號碼，或用 at()。到上面的「錯誤實驗室」親身體驗看看。
📝 搬家後，紙條作廢
重新配置（搬家）之後，之前記住的位址就失效了。需要位址時，搬完家要重新拿一次。

💻 真正的程式碼長這樣

當你在上面按按鈕時，對應的這一行會亮起來！

📦 vector：會變大的盒子
vector<int> balls;          // 建立一個空盒子

balls.push_back(10);         // 🟢 加一顆球（盒子會自動變大）
balls.insert(balls.begin(), 5); // ✂️ 插隊到最前面
int v = balls[0];            // 拿 0 號（第一顆，從 0 開始！）
balls.pop_back();             // 🔴 拿走最後一顆
balls.reserve(100);          // 📐 預約大盒子
balls.shrink_to_fit();       // 📏 縮回剛剛好
balls.clear();               // 🧹 全部清空
int n = balls.size();        // 現在有幾顆？
🍱 array：固定的便當盒
// 出廠就是 8 格，不能多也不能少
array<int, 8> bento = {1,2,3,4,5,6,7,8};

bento[0] = 100;              // ✅ 可以改球上面的數字

// bento.push_back(9);        // ❌ 編譯就報錯：不能加！
🛡️ 安全拿東西的方法（對應「錯誤實驗室」）
int bad = balls[99];         // ❌ 危險：99 號不存在，卻沒有警告！

if (i < balls.size()) { ... }  // ✅ 做法①：拿之前先檢查

try {
    int v = balls.at(99);     // ✅ 做法②：用 at()，出錯會丟出例外
} catch (...) {
    // 出錯時來到這裡，程式不會崩潰
}
